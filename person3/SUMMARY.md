# Zaalima Data Analytics - Project Summary

## Project Overview
Customer Churn Prediction and LTV Analysis for Telco dataset.

## Team Member: Renuka (Person 3)

### Week 1 - Data Preprocessing
- Data inspection and missing value handling
- Label encoding for categorical variables
- Baseline analytics: churn rate, retention rate

### Week 2 - Feature Engineering & Modeling
- Tenure and charges based feature engineering
- Logistic Regression model training
- XGBoost classifier with SHAP analysis
- Model evaluation: Accuracy, ROC-AUC, Confusion Matrix

### Week 3 - LTV Analysis
- Customer Lifetime Value (LTV) calculation
- Linear Regression for LTV prediction
- Random Forest regression model
- Model comparison and evaluation

### Week 4 - Business Churn Analysis
- Churn trend analysis by contract, payment, service
- Customer segmentation (New, Growing, Premium, Loyal)
- Business churn report generation
- Visualization dashboard

## Key Results
- Overall Churn Rate: ~26%
- Best Model: XGBoost (ROC-AUC ~0.84)
- High Risk Segment: Month-to-month contract customers

## Tech Stack
- Python, Pandas, Scikit-learn, XGBoost, SHAP
- PostgreSQL, SQLAlchemy
- FastAPI, Docker
- Matplotlib, Seaborn
