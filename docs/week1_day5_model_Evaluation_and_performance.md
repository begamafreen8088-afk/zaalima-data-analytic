# Week 2 Day 5: Model Evaluation and Performance Analysis

## Objective

Evaluate the performance of the trained Logistic Regression model using classification metrics and visualization techniques.

## Goals

- Evaluate model performance using classification metrics.
- Analyze the confusion matrix.
- Generate ROC Curve and AUC Score.
- Interpret the model results.
- Document key findings and conclusions.

## Tasks Performed

1. Trained the Logistic Regression model.
2. Generated predictions on the test dataset.
3. Calculated Accuracy Score.
4. Generated Classification Report.
5. Created Confusion Matrix visualization.
6. Calculated ROC-AUC Score.
7. Generated ROC Curve.
8. Built a performance dashboard for model evaluation.

## Results

### Accuracy Score

The model achieved good predictive performance on the test dataset.

### Classification Report

The classification report provided Precision, Recall, F1-Score, and Support values for evaluating the model.

### Confusion Matrix

The confusion matrix showed the distribution of correct and incorrect predictions and helped assess model effectiveness.

### ROC-AUC Score

ROC-AUC Score: **0.8408**

This indicates good model performance in distinguishing churn and non-churn customers.

## Visualizations Generated

- Confusion Matrix Heatmap
- ROC Curve
- Performance Dashboard

## Key Findings

- Logistic Regression successfully captured customer churn patterns.
- The ROC-AUC score indicates strong classification capability.
- Most customer churn predictions were classified correctly.
- The model provides a solid baseline for churn prediction tasks.

## Conclusion

The Logistic Regression model was successfully evaluated using multiple classification metrics and visualization techniques. The model achieved a ROC-AUC score of approximately 0.84, demonstrating good predictive capability. The evaluation results indicate that the model can effectively identify customer churn behavior and support business decision-making.
