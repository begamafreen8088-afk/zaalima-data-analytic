# Week 4 - Day 3

## Task: LTV Analysis Dashboard

### Objective
Analyze Customer Lifetime Value (LTV) and revenue-related metrics using the Telco Customer Churn dataset.

### Dataset
- Database: PostgreSQL
- Table: telco_customer_churn
- Records: 7043

### Dashboard Components

#### 1. Average Monthly Charges
- Visualization: Number Card
- Purpose: Display average monthly revenue per customer.

#### 2. Average Tenure
- Visualization: Number Card
- Purpose: Show average customer retention period.

#### 3. Monthly Charges by Contract Type
- Visualization: Bar Chart
- Purpose: Compare revenue across contract types.

#### 4. Monthly Charges by Internet Service
- Visualization: Bar Chart
- Purpose: Analyze revenue contribution by service type.

#### 5. Tenure Distribution
- Visualization: Histogram / Bar Chart
- Purpose: Understand customer retention patterns.

### Dashboard Name
LTV Analysis Dashboard

### Tools Used
- PostgreSQL
- Metabase
- SQL

### Outcome
Successfully created an LTV Analysis Dashboard to analyze customer value, revenue trends, and retention behavior.
