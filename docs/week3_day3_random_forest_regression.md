# Week 3 - Day 3: Random Forest Regression Model Training

## Objective

The objective of this task was to train a Random Forest Regression model using the prepared Customer Lifetime Value (LTV) dataset. The model was developed to learn patterns from customer-related features and generate LTV predictions. This task also aimed to prepare a robust regression model for future evaluation and comparison with other regression techniques.

## Dataset

LTV Prepared Dataset (ltv_prepared_dataset.csv)

## Implementation Steps

1. Loaded the prepared LTV dataset.
2. Selected input features and target variable (LTV).
3. Split the dataset into training and testing sets.
4. Created and trained a Random Forest Regression model.
5. Generated predictions using the trained model.
6. Saved the trained model for future evaluation and comparison.


Results

The Random Forest Regression model was successfully trained using the prepared dataset. The model generated LTV predictions and was saved for further analysis and performance evaluation.

Conclusion

The Random Forest Regression model was successfully developed and trained for Customer Lifetime Value prediction. The trained model captured relationships between customer features and LTV, providing a strong foundation for performance evaluation and comparison with other regression models in the next stage of the project.
