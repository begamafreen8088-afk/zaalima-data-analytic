# Week 3 - Day 4: Model Evaluation and Comparison

## Objective

The objective of this task was to evaluate and compare the performance of the Linear Regression and Random Forest Regression models for Customer Lifetime Value (LTV) prediction. The comparison was performed using standard regression evaluation metrics to identify the most effective model.

## Dataset

LTV Prepared Dataset (`ltv_prepared_dataset.csv`)

## Models Evaluated

1. Linear Regression
2. Random Forest Regression

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Implementation Steps

1. Loaded the trained Linear Regression and Random Forest Regression models.
2. Generated predictions on the test dataset.
3. Calculated MAE, RMSE, and R² Score for both models.
4. Compared the performance of the models using evaluation metrics.
5. Analyzed the results to identify the better-performing model.





## Conclusion

The Linear Regression and Random Forest Regression models were successfully evaluated and compared using MAE, RMSE, and R² Score metrics. The evaluation process enabled the identification of the most suitable model for Customer Lifetime Value prediction. The selected model can be used in subsequent stages of the project to support data-driven business decisions and customer retention strategies.
